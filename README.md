# 📊 Amazon Sales Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on an Amazon product sales dataset. The purpose of this analysis is to better understand the dataset structure, detect patterns, explore relationships between variables, and extract insights that can support business decisions such as:

* Improving pricing strategies
* Identifying high-performing product categories
* Understanding customer review trends
* Evaluating discount impact on sales and ratings

The dataset contains product-related information such as pricing, discount details, product ratings, number of reviews, and product categories.

---

## 🗂 Dataset Description

The dataset includes the following types of features:

* **Product Name / Category**
* **Original Price**
* **Discounted Price**
* **Discount Percentage**
* **Ratings**
* **Number of Reviews**
* **Sales / Purchase Trends (if available)**

---

## 🛠 Libraries Used

The notebook uses the following Python libraries:

* **pandas** – data manipulation and preprocessing
* **numpy** – numerical computations
* **matplotlib** – data visualization
* **seaborn** – advanced statistical visualization

---

## 🔍 Key Analysis Performed

The notebook covers:

* Data loading and inspection
* Handling missing values and duplicates
* Data cleaning and formatting
* Summary statistics
* Category-wise analysis
* Price vs discount comparisons
* Ratings and review trends
* Visualization of distributions and correlations
